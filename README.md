PhishGuard — AI Phishing Investigator

About

PhishGuard is a hackathon project exploring how AI can help users investigate suspicious URLs and messages.

Problem

Phishing attacks use deceptive links and messages to trick people into revealing sensitive information.

Proposed Solution

PhishGuard aims to analyse suspicious inputs, identify potential warning signs, explain possible risks, and recommend safer actions.

Planned Features

- URL and message analysis
- Detection of potential phishing indicators
- Risk assessment with clear explanations
- Safety recommendations

Technologies

- Python
- AI-assisted analysis
- Web interface (planned)

Status

Currently in development. Features are proposed and will be updated as they are implemented.
